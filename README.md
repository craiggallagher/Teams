# Premier League Teams Manager

A learning project built with .NET 10, ASP.NET Core Web API, WPF and Entity Framework Core.

The application will allow users to manage Premier League football teams, including their stadium capacity, establishment date and club crest.

## Technologies

- C# / .NET 10
- ASP.NET Core Web API
- WPF
- Entity Framework Core
- SQL Server LocalDB

## Project Structure

- `Team.Api` - ASP.NET Core Web API and database access.
- `Team.Wpf` - WPF desktop application.

## Planned Features

- [x] SQL Server database setup
- [x] Team entity and database migrations
- [x] Team DTOs
- [ ] Create, read, update and delete teams
- [ ] WPF user interface
- [ ] Connect WPF application to the API
- [ ] Display club crests and team information
